# Build Track

An Expo app using file-based routing with [Expo Router](https://docs.expo.dev/router/introduction).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

Routes live in the `src/app` directory. The root layout is a single stack, and `/` opens the home screen. The URL scheme is `buildtrack`.

Light and dark colors follow the system color scheme.
